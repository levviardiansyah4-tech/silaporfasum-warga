KEAMANAN WEBSITE PENGGUNA SILAPORFASUM
- Jangan unggah file konfigurasi rahasia atau password ke repository publik.
- Jangan pernah memakai Supabase service_role key di HTML atau JavaScript frontend.
- Gunakan publishable/anon key dan pastikan kebijakan Row Level Security (RLS) Supabase sesuai kebutuhan.
- Gunakan HTTPS untuk kamera, GPS, service worker, dan instalasi PWA.
- Website ini merupakan prototipe; lakukan pengujian keamanan sebelum digunakan secara luas.
